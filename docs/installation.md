# Setting up the Environment
This task shows you how to set up the environment for Structure Functional Design. You need to assign resources in the Data Setup and customize preferences.
## Import Materials
You need to import materials to the database to make them available.
1. From the top bar, select `Add`  > `Import` > `3DXML`.
The `Import 3D XML` dialog box appears.
1. Click `[...]` to choose a folder.
1. Select the required path and click `Select Folder`.
1. Select the required *.3dxml* file and click `OK`.
   **Note:** You can create materials in the session.

## Set up your Session
You can assign resources in Data Setup and set required options in `Me`  > `Preferences`.
1. Assign Common geometry resources, structure resources, and structure library resources.
2. Associate these resources with projects.
3. Select `Share`  > `Save` > `Save with Options` to save the changes.
The environment is set for the **Structure Functional Design** app.
