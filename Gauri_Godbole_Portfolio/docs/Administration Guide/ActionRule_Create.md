#Creating an Action Rule
You can create an action rule to define certain rules and execute the rule when you start with a command.
1. From the top bar, select Add  > Content.
2. In the **New Content** panel, select **3D Shape** under the **Physical Product Structure** category.
3. From the **Compass**, click **Engineering Rules Capture**.
4. From the **Engineering Rules Capture section** of the action bar, click **Actions**.
5. Enter the required details:
   1. In the **Argument list** area, enter the name of the required argument and define its type.
   2. Enter the required action rule.
   3. Click **OK**.
6. In the tree, right-click **Action.x** and select **Properties**.
7. In the **Name** box, enter the required action rule name and click **OK**.

*Tip:* You can also create an action rule under a physical product. To do so:
1. From the top bar, select **Add** > **Physical Product**.
1. Switch to the **Engineering Rules Capture** app.
1. In the **Knowledge Engineering Specification Physical** dialog box, enter the required name.
1. In the **Action Editor: Action** dialog box, enter the required details as above.
1. An action, identified as **Action.x**, is created in the tree.
