# Structure Functional Design

## Main Capabilities

- Addresses functional design requirements for the  shipbuilding industry.
- Builds on the conceptual design letting you refine and strake the hull, add plate thicknesses to decks and bulkheads, and define longitudinal and transverse stiffener systems.
- Enables you to gauge the openings, end cuts, slots that you need for the passing of profiles, like stiffeners and beams.

## Related Apps

- Structure Design: Provides a set of tools for structure designers to complete their functional design and carry out their detailed design.
- Space Referential: Lets you create a reference plane system and modify it.
- Generative Shape Design: Lets you create surfaces and volumes.
- Multi-Discipline Drafting: Lets you generate drawings from 3D parts and assembly definitions.

## Terminology
### Structure system
Structure system is the 3D part, which consists of structural components such as shells, decks, bulkheads, stiffeners, and openings. It is used for preliminary design of ship.
### Structure Design Unit
Structure design unit is the division of structure systems, which is the preliminary design, into manufacturing blocks. It represents the detailed design of a ship.
### Panel
It is the main surface-based structural element that is used to create shell, deck, or bulkhead.
### profile
Profile is a stiffener or a beam that is used to provide strength, stability, and rigidity to panels.
