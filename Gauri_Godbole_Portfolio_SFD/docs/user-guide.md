# Creating a Structure System
## Create the Structure

1. In the top bar, select `Add`  > `Content`.
The `New Content` dialog box appears. It lists the `Favorites`, the `Most Recently Used` objects and various categories. 
1. Expand the `Structure` category.
    The list contains:
   - Structure Contour
   - Structure Design Unit
   - Structure Endcut
   - Structure Opening
   - Structure Section
   - Structure Slot
   - Structure System
1. **Optional:** Right-click `Structure System`  and select `Set attributes` at creation to define specific attributes during the creation of the structure system.
2. Click `Structure System` .
The `Structure System` dialog appears.
1. In the `Structure System` tab, specify the following:
   1. Enter the required title.
   2. Select the design range.
1. Click the `Create Project Data` tab and select the required reference plane system from the `Reference` list.
The list contains all the reference planes systems assigned in data setup. By default, the reference plane system assigned to **Common Reference System resource** is selected.
1. lick **OK**.
A new structure system is created. You can notice the structure system icon in the tree. The project data is also created.
